### Simple Calculator

This is a basic *Simple Calculator* web application built using HTML, CSS, and JavaScript. It allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

#### Features:
- Interactive user interface with buttons for numbers and operators.
- Responsive design that adjusts to different screen sizes (mobile, tablet, desktop).
- Supports basic arithmetic calculations and error handling.
- Clean and modern layout with hover effects for buttons.

#### Technologies Used:
- *HTML:* Structure of the calculator interface.
- *CSS:* Styling for the layout and responsive design.
- *JavaScript:* Functionality for number input, operations, clear, and calculation.

#### How to Use:
1. Click the buttons to input numbers and operations.
2. Press the "=" button to calculate the result.
3. Press "AC" to clear the display.
